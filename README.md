# 大话骰微信小程序

这是需求文档 V1.0 对应的原生微信小程序 MVP。目前完成非视觉部分：项目骨架、骰子随机逻辑、页面状态机、点击开合盖、重复点击保护和音效容错接口。

## 本地运行

1. 使用微信开发者工具导入本目录。
2. 开发阶段可使用测试号；正式发布前把 `project.config.json` 中的 `appid` 替换为真实小程序 AppID。
3. 点击编译即可进入单页功能界面。

## 自动化测试

使用已配置的 Node.js 运行：

```powershell
npm test
npm run check
```
