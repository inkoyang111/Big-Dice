# 大话骰微信小程序

原生微信小程序实现的单页大话骰工具。V1 已正式发布；V2 已完成快速双击隐藏触发功能、自动化测试和微信开发者工具验证。

## 当前功能

- 固定生成 5 颗、点数为 1～6 的骰子。
- 1.5 秒摇骰动画及本地音效。
- 摇完后点击骰盅开盖/合盖，结果在本轮保持不变。
- 防重复摇骰、初始态误点提示和前后台状态处理。
- 300ms 内快速双击“摇一摇”或“再摇一次”，本轮 5 颗骰子至少包含 3 个随机位置的 1；不显示额外提示，也不重复动画或音效。
- 完整本地视觉资源，无登录、支付、用户数据收集或网络接口。

## 本地运行

1. 使用微信开发者工具导入仓库根目录。
2. 项目 AppID 为 `wx7f6aa6ea7f4a818c`。
3. 点击“编译”即可运行；发布前先完成模拟器、真机和体验版验收。

## 开发与验证

要求 Node.js 24 或更高版本：

```powershell
npm install
npm test
npm run check
```

重新生成运行时图片资源：

```powershell
npm run prepare:assets
```
